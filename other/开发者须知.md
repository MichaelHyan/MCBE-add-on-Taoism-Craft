## 仓库管理

### 如何合作（git fork）

第一步：用 GitHub Desktop 克隆 fork 到本地

- 打开 GitHub Desktop
- 菜单 File → Clone Repository
- 切到 URL 选项卡，粘贴你 fork 的仓库地址（https://github.com/MichaelHyan/MCBE-add-on-Taoism-Craft）
- 选择 Local Path（本地存放目录）
- 点击 Clone
- 如果你是用的"先 clone 原仓库再推送触发 fork"的方式：clone 原仓库地址 → 改完代码尝试发布分支 → 弹出 fork 确认框 → 选 To contribute to the parent project → Continue。

第二步：保持与上游同步（建议做）
- 为了避免你的 fork 落后太多导致 PR 冲突：
- GitHub Desktop 菜单 Repository → Repository Settings → Remotes
- 点击 Add，添加原仓库为上游源：
- Name: upstream
- URL: https://github.com/MichaelHyan/MCBE-add-on-Taoism-Craft
- 保存后回到主界面，点 Fetch origin 拉取更新
- 菜单 Branch → Merge into current branch，选择 upstream/main，点击合并

第三步：创建特性分支并改代码
- 左上角 Current Branch 下拉 → New Branch
- 输入分支名，建议带前缀：
    - fix/xxx —— 修 bug
    - feat/xxx —— 新功能
    - docs/xxx —— 文档
- 点击 Create Branch
- 用编辑器改代码
⚠️ 永远不要直接在 main 分支上改，一定开新分支。

第四步：提交改动
- GitHub Desktop 左侧 Changes 面板会列出所有改动文件
- 勾选要提交的文件（不要无脑全选）
- 左下角填写提交信息：
- Summary（必填）：简短说明更改内容
- Description（可选）：详细描述
- 点击 Commit to 你的分支名

第五步：推送到你的 fork
- 提交后，顶部会出现 Publish branch 按钮
- 点击它将分支推送到 GitHub 上的你的 fork
- 第七步：发起 Pull Request
- 推送完成后，顶部出现 Create Pull Request 按钮
- 点击 Preview Pull Request 查看差异，或点 Create Pull Request 直接进入浏览器
- 在浏览器打开的页面中确认：
    - base repository：原仓库（如 原作者/仓库名）
    - base branch：通常是 main
    - head repository：你的 fork
    - compare branch：你刚推送的特性分支
    - 填写 PR 标题和描述（说明改了什么、为什么改）
- 点击 Create Pull Request

### 如何合作（无git）

- 向管理员索要最新开发版
- 在该基础上修改，另开一个文件记录修改位置，形式不限
- 将修改后的文件和记录修改位置的文件发送给管理员

### 协作者（Contributors）

如果确认长期合作，可向管理员(韩言悦欣)申请协作者身份，通过后可将自己的账号关联为仓库协作者

协作者身份拥有全部仓库管理权限

### 贡献修改可以获得什么回报？

可以在下次release中提名

可以在下次更新视频中以合作者身份发布

可以把群主打服后迫使其女装，管理员将不提供帮助

## 如何使用模组

### 游戏下载地址

[地址](https://mc.minebbs.com/)

1.21.100以上即可，新版版本号，如26.x均可使用

### 打包模组

如果你使用mcaddon版本，则跳过这一步

同时选中文件夹Taoism_B(行为包)和Taoism_R(资源包)

右键压缩为zip

后缀改为mcaddon

### 加载模组

手机端：

- 任意文件管理器中找到mcaddon文件
- 打开方式，如显示打开为xx格式则随便选，最后选择打开方式为minecraft

pc段端：

- 双击后将自动启动并导入

### 手动

找到文件夹C:\Users\用户名\AppData\Roaming\Minecraft Bedrock\Users\Shared\games\com.mojang

将文件夹Taoism_B(行为包)和Taoism_R(资源包)分别复制进文件夹behavior_packs和resource_packs
