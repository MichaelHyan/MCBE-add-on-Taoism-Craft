# 引导 NPC 交互文本总表

> 版本：草案 v2
> 范围：只做「手持物品右键 → 返回提示」和「空手右键 → 通用开场」两种交互。
> 不做阶段推进、不做主动冒泡、不做事件触发。玩家不问，NPC 不响。
> **收录口径**：只收 `README.md` 中明确写到条目的物品。README 未记载的物品一律不收录。
> 物品标识符已从 `Taoism_B/items/*.json` 实际提取核对；中文名取自 `Taoism_R/texts/zh_CN.lang`。

---

## 一、交互模型

| 玩家操作 | NPC 反应 |
|---|---|
| 手持物品右键 NPC | 查本表，返回该物品提示；查不到则回兜底句 |
| 空手右键 NPC | 返回第四章的通用开场 |

---

## 二、数据结构建议

```json
{
  "items:pearl": {
    "name": "内丹",
    "level": null,
    "hint": "你的产能核心。交互运气出元气；【法】模式下绑了秘籍还能放法术。"
  }
}
```

- `name`：中文名，用于兜底和调试。
- `level`：等级门槛，取自 `zh_CN.lang` 的「等级限制」字段。`null` 表示无门槛。若不为 `null`，脚本可在提示末尾自动补一句「要 X 级才亮特效」，不必逐条手写。
- `hint`：正式提示文本。

## 三、开局赠予清单

> 只列清单与数值依据，不含发放逻辑。

| 物品 | 标识符 | 数量 |
|---|---|---|
| 元气 | `items:spe` | 3 |

**数值依据**

- 朱砂粉 = 1 元气 + 1 朱砂晶体，一次出 3 份。
- 经书需 7 朱砂粉 + 1 普通毛笔 + 1 本书；画符毛笔另需 1 朱砂粉。
- 3 次合成 = 3 元气 + 3 朱砂晶体 → 9 朱砂粉 → 7 做经书、1 做画符毛笔，余 1。
- 整包的前期门槛就是「3 个元气」，给 3 个正好闭环。

**待补充**：是否额外给一本书、一支普通毛笔。按当前数值玩家自己能搓，建议不给，留作第一批动手目标。

## 四、空手右键通用文本

> 这包东西靠问的。拿着什么来点我，我告诉你它是干嘛的、坑在哪。
>
> 先提一句最要紧的：**物件都有等级门槛，等级不到，面板照给，特效是哑的。**
>
> 起点是朱砂——砍亡灵掉晶体，一个元气配一个晶体出三份粉，七份粉配一支普通毛笔和一本书，就是经书。
>
> **经书只在亏凸月、盈凸月修得成**，别的日子用了遭雷劈。做之前先弄个浑仪看月相。

**兜底句**（手上物品不在表里时）：

> 这个我还没摸透，你先收着。

## 六、非物品条目的处理方式

生物和机制没法直接「拿东西问」，用**掉落物代问**，不另开触发：

| 玩家手持 | 附加提到的内容 |
|---|---|
| `items:pearlz_o` 尸丹 | 旱魃：满月新月出，血厚伤害高会强化僵尸，怕雷怕水 |
| `items:pearlz_p` 尸丹残片 | 跳僵：夜里出，慢，好打 |
| `items:soul_powder` 阴魄砂 | 伏尸：地下埋着，踩过去突然探头 |
| `items:pill` 小还丹 | 鬼：睡觉七分之一概率闹，吃小还丹挡阳气 |
| `items:cinnabar_crystal` 朱砂晶体 | 亡灵：僵尸骷髅都掉 |

- **巧思**：游商、游侠没有对应掉落物，暂不写。若要讲，可用 `items:cinnabar_powder` 代问（朱砂换秘籍和家具）。
- 尸变与赶尸贴符已在 `items:talisman` 提示里带了，不另列。
